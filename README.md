## 🚀 The Problem & The Solution

In India, over 400 million people use multiple systems of medicine concurrently. When an allopathic doctor prescribes Amlodipine (blood pressure) and an Ayurvedic doctor prescribes Sarpagandha (Rauwolfia), the combination causes severe bradycardia. **Until CURA, no software existed to catch this.**

CURA features a **Patent-Pending Cross-Domain Safety Engine** driven by a Python FastAPI microservice containing 30+ interaction pathways researched directly from NIH and PubMed.

## 🛠️ Tech Stack & Microservice Architecture

- **Frontend:** Next.js (App Router), React, Tailwind CSS
- **Node Backend:** Next.js API Routes (Auth, Data passing)
- **AI Engine Backend:** Python FastAPI (OCR, NER, Interaction Logic)
- **Future Database:** PostgreSQL via Prisma (v3 roadmap)

## ⚙️ Running Locally (Docker & Dev Servers)

CURA requires both the Next.js frontend and the FastAPI backend to be running.

### 1. Start the Fast API AI Engine
```bash
cd ai-backend
python -m venv venv

# Windows
venv\Scripts\activate
# Mac/Linux
source venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
*The AI documentation is now available at `http://localhost:8000/docs`*

### 2. Start the Next.js App
In a new terminal wrapper, from the project root:
```bash
npm install
npm run dev
```
*The platform is now available at `http://localhost:3000`*

### 🐋 Docker (Coming Soon)
To run the full stack via Docker Compose:
```bash
docker-compose up --build
```
*(Note: docker-compose.yml is in development for v3 Database release)*
